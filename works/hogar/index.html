Wall-mounted IoT switches across three sizes

Project preview - replace with 1600 x 900 px PNG
Overview
CompanyUX Labs
RoleUI/UX Designer
CategoryIoT / Hardware
Year2019
The Project

A line of wall-mounted IoT switch controls across three physical sizes, each with its own touch interface for controlling lights, fans, and home appliances.

What I Did

Designed user flows for the three switch sizes and worked with the design team to establish shared interaction patterns that adapted to each form factor.

Challenges

Hardware constraints behave differently from software constraints. The smallest switch had very limited screen space while the largest allowed richer controls, so maintaining one consistent mental model was the core challenge.

Outcome

Designs shipped to manufacturing for the IoT switch product line.
