Philips DECT Phone OS

Interface design at the hardware OS level

Project preview - replace with 1600 x 900 px PNG
Overview
CompanyOghma
RoleUI Designer
CategoryHardware / Consumer Electronics
Year2011
The Project

Philips's DECT cordless phone operating system: the interface layer on Philips home and business cordless phones, covering menus, contacts, call handling, settings, and system flows.

What I Did

Contributed UI design and workflow design as part of the design team, working on screens and interaction patterns within the broader OS.

Challenges

Hardware OS design is different from app or web design. Screens are small, input uses physical buttons, and every interaction has to work within tight memory and processor constraints.

Outcome

Interface shipped as part of Philips's DECT phone product line.
