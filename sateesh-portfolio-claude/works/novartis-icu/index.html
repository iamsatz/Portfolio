Novartis ICU

Tablet interface for ICU patient monitoring

Project preview - replace with 1600 x 900 px PNG
Overview
CompanyOghma
RoleUI Designer
CategoryHealthcare / Tablet
Year2013
The Project

A tablet-based patient monitoring system for Novartis, used by hospital staff to monitor ICU patients across vital signs, medications, and care interventions.

What I Did

Contributed UI design as part of the design team, working on tablet interface screens within the broader system.

Challenges

ICU contexts are unforgiving. Every screen has clinical implications, so the team had to design for medical professionals operating under fatigue, time pressure, and life-critical decisions.

Outcome

Interface shipped as part of Novartis's hospital monitoring solution.
