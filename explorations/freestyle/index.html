Chrome Extension · Work in Progress

FreeStyle

A design-system auditor for the browser, scan, inspect, replace, and audit colors, typography, and accessibility on any webpage.

The Concept

Designers spend a lot of time poking at live websites, pulling colors, naming fonts, checking contrast, imagining a rebrand. The tools for it are scattered and half-broken: one extension reads styles but can't change them, another swaps a color but falls apart the moment you hover.

FreeStyle is one extension that does the whole loop: inspect like CSS Peeper, rebrand like a design tool, audit like an accessibility checker. Scan any page, see exactly how it's built, try changes live, and export the result in whatever format your stack speaks.

Built for product designers, developers, and brand designers, anyone who reverse-engineers and reworks the look of real pages.

What It Does
ScanExtract every color, CSS variable, font, and text style from any page.
InspectPoint-click element inspector with a box-model overlay, computed styles, and inline contrast ratios, CSS Peeper-level detail.
ReplaceLive color and font replacement that holds up across hover, focus, and active states.
AuditWCAG 2.1 + APCA contrast checking with auto-fix suggestions.
ExportJSON, CSS, SCSS, Tailwind, Figma Tokens, or an SVG palette.
Why It Exists

Existing tools are either read-only (CSS Peeper) or break when you try to replace colors on hover states. FreeStyle solves both at once, and folds in the accessibility check most of them skip entirely.

Read-only is half a toolSeeing the styles isn't enough; designers want to try a change and see it live.
Replacement that survives stateMost live-edit tools forget hover/focus/active, so the "after" never looks real.
Accessibility shouldn't be a separate appContrast belongs right next to the color you're changing, not in another tab.
How It's Built, The Moat

The core trick is an immutable scan layer with a separate override layer. The original page styles are captured once and never mutated; edits live in an overlay on top. That's what makes color replacement survive hover and focus states instead of silently breaking, the bug that sinks most "live rebrand" tools.

ArchitectureChrome Extension (Manifest V3), side-panel UI, vanilla ES6+ with zero dependencies.
ContrastAPCA-W3 algorithm alongside WCAG 2.1, modern perceptual contrast, not just the legacy ratio.
